## What to Test

Thanks for testing Veloseete. This build ships **Tracky mood app icons** and splits **Driver** (you) from **Garage** (the car).

### App icons (Tracky moods)
- Primary icon = Chill Tracky (full-bleed lime).
- Changing Tracky mood on **Driver** should switch the home-screen icon (Proud, Fueled, Focused, Night, Dawn, Grit, Legend, Cozy).
- Icons should look full-bleed (no floating circle avatar).

### Driver vs Garage
- **Driver** is about *you*: “Your driving”, Calm → Spirited style bar, this month distance / drives / hours / top speed.
- Car fuel thirst (“Needs some love”, Thrifty → Thirsty, L/100) moved to **Garage** as **Car fuel status**.
- Fuel spend / efficiency charts removed from Driver.

### Still worth checking (from build 24–26)
- Inline Tracky mood picker, badges, map tracker stability, profile photo reload.
- Garage multi-car + sign-out.
